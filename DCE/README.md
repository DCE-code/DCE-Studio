# DCE Studio

DCE Studio is a cinematic portfolio for frontend engineering, UI/UX design, and Python-powered web applications. It is built to feel like a product experience: fast to scan, intentional in motion, and useful to both clients and recruiters.

## What is inside

- Responsive React single-page portfolio
- Cinematic first-visit intro with session memory
- Filterable project showcase with accessible detail modals
- Recruiter Mode for a focused professional view
- Persistent light and dark themes
- Contact form, email, phone, and WhatsApp pathways
- Ambient motion layer with a lightweight rendering footprint

## Technology

React 18, Vite, Tailwind CSS 4, Framer Motion, React Icons, and Python as part of the studio's web application toolkit. Python is positioned for APIs, automation, data workflows, and the application logic behind polished frontend experiences.

## Run locally

From the `DCE` directory:

```bash
npm install
npm run dev
```

On Windows PowerShell systems where script execution is restricted, use:

```powershell
npm.cmd run dev
```

Then open the local URL printed by Vite, normally `http://localhost:5173`.

## Production checks

```bash
npm run lint
npm run build
```

Use `npm run preview` to inspect the production build locally.

## Project map

```text
src/
  components/   Section-level UI and interactive experiences
  data/         Structured portfolio content
  assets/       Local static assets
  App.jsx       Application shell and theme state
  index.css     Tailwind entrypoint and theme overrides
```
